# Home Assistant Add-on: Shelfmark

![Supports aarch64](https://img.shields.io/badge/aarch64-yes-green.svg)
![Supports amd64](https://img.shields.io/badge/amd64-yes-green.svg)

[Shelfmark][shelfmark] is a self-hosted web interface to search and download
books and audiobooks from multiple sources:

- one search across direct download, torrent, usenet, IRC and Soulseek sources;
- rich metadata from Hardcover, Open Library, Google Books and more;
- multi-user with requests and approvals;
- live download queue.

This add-on saves downloads into the **Calibre-Web Automated** ingest folder
by default, so new books land in your library automatically, and it can mark
books you already own.

Opens inside Home Assistant through **Ingress** (also remotely), plus a
direct LAN port.

See the **Documentation** tab for configuration details.

[shelfmark]: https://github.com/calibrain/shelfmark
